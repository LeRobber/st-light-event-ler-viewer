# st-light-event-ler-viewer

Summon the popup window AFTER you have loaded the unruly chat by using the /ler-viewer command. 

This extension shows lists of events that occur with timings for debugging purposes in SillyTavern/Aikobots.

If you uncheck an event's name in filters, it will redact the contents of those events. 

Many sensitive fields are already redacted because, this tool is meant to help debug someone else's problem. Chats sometimes contain fun/characters we didn't necessarily write for publication to share with everyone.

You can click the 'payload' to expand out the contents of some events. 

This just displays events. This doesn't take anything off your computer, etc. Its just the stuff in st/ab between your web page and the st/ab server, per what the web page thinks is an event. 

This doesn't show passwords or api keys that I've SEEN, but I haven't extensively tested you CHANGING those while its running. But the payload should be collapsed for those, anyhow, so unless you toggle them open on like a video, I doubt you'll have a problem. 

It may hide a few noisy events entirely as development moves forward.
